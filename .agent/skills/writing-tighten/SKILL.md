# Writing — Tighten

Run a draft through a fixed checklist, report what fails, and fix it **with** the user — one rule at a time, their call on every change.

Rules adapted from Kaguura Gichuru, ["20,585 New Subscribers in 90 Days"](https://kaguura.substack.com/p/90-days-20585-new-subscribers-heres) (Jul 2026).

## The rules

Each rule is a pass. Check them in this order — structural cuts first, so you don't line-edit sentences that are about to be deleted.

### 1. Kill the warm-up
The opening paragraphs explaining why this piece exists are for the writer, not the reader. Cut until the first sentence is already inside the subject.

### 2. Second draft = first draft − 10%
Find the repetition, the throat-clearing, the safe filler, the sentence that restates the one before it. Every sentence must advance the point or it goes. If the draft doesn't shrink by roughly a tenth, the pass wasn't honest.

### 3. One reader, not a stadium
No "Hey guys", "everyone", "you all", "those of you who". Address one person as "you". The writing should read like it was sent, not broadcast.

### 4. Kill adverbs
An adverb propping a weak verb is one word doing half a job. "Ran quickly" → "sprinted". "Said angrily" → "snapped". Flag every `-ly` and ask what single verb replaces the pair. Some survive — the test is whether the verb alone is weaker.

### 5. Active voice
The subject acts; it isn't acted upon. "The article was noticed by Michael Burry" → "Michael Burry noticed the article." Passive costs a beat and hides who did what. Keep it only when the actor is genuinely unknown or irrelevant.

### 6. Concrete over abstract
Abstractions don't stick. "Shoveling dirt for $10 a day" beats "economic hardship". For every abstract noun — *growth, value, impact, engagement, hardship* — ask what it looks like, and swap in the image. If a sentence can't be pictured, it won't be remembered.

### 7. Short sentences, plain words
Explain it the way you'd explain it to a friend at a bar. Break any sentence carrying more than one idea. Jargon and corporate register are a tax the reader pays for nothing — flag each instance and offer the plain word.

### 8. Spacing is pacing
Vary paragraph length deliberately: short to accelerate, longer to slow the reader through something hard. Flag walls of text (they get skipped) and the opposite tic — every sentence on its own line, which reads as affectation and flattens all emphasis.

### 9. Titles and headings
If the piece has a title or section headings, each should carry a number or a specific detail, show its value immediately, and sound like a real person texting a solution. Poetic vagueness ("Sifting Through the Noise") and academic dryness ("An Analysis of High-Growth Models") both fail. Offer 5–8 title options when the current one is weak.

## How to run it

1. **Read the whole draft first.** Note what the piece is actually trying to do — the rules serve the argument, not the reverse.

2. **Do one pass per rule, in order.** For each pass, collect every violation before saying anything. Report them as a numbered list, each with the quoted original, the suggested replacement, and a few words on why. Nothing more — no essay about the rule.

   ```
   Rule 4 — adverbs (6 found)

   1. L12  "moved quickly through the list"  →  "raced through the list"
   2. L31  "he completely rejected it"       →  "he rejected it"  (adverb adds nothing)
   ...
   ```

3. **Ask before editing.** "Apply all, or pick numbers?" Accept any answer — all, a subset, none, or a counter-suggestion. Apply exactly what they chose, then move to the next rule. Don't queue up all nine passes and edit in one go; the point is that they see and steer each one.

4. **Report the word count** after the 10% pass, before and after.

## Judgment

- **Their voice is the asset.** These rules remove flab, not personality. A deliberate fragment, a repeated line for rhythm, a long unspooling sentence that earns its length — leave them, and say why you left them if the user expects a flag.
- **Never rewrite unasked.** Show the edit, get the nod, then apply. A rewrite the user didn't approve is a draft they no longer own.
- **Flag, don't argue.** If the user rejects a suggestion, drop it and move on. Don't re-raise it in a later pass.
- **Zero findings is a valid result.** If a pass turns up nothing, say so in one line and continue.

## Finishing

When the passes are done, give a short summary: word count before/after, which rules bit hardest, and the one habit worth watching in the next draft. One paragraph — don't grade the piece.
